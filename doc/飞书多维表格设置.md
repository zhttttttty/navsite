
# 飞书多维表格设置

1. **创建表格**
   - 在飞书中进入云盘（注意：不能在知识库中创建）
   ![进入云盘](./images/1.png)
   - 新建多维表格，表格名称建议：`导航网站数据`
    ![新建多维表格](./images/2.png)

2. **设置字段**（字段名称区分大小写，必须严格一致）

   | 字段名称 | 字段类型 | 是否必填 | 当前状态 | 说明 |
   |---|---|---|---|---|
   | `name` | 单行文本（主字段） | 是 | 已使用 | 网站名称 |
   | `url` | 单行文本 | 是 | 已使用 | 完整的网站地址，例如 `https://github.com` |
   | `category` | 单选 | 是 | 已使用 | 网站分类，例如“开发”“设计” |
   | `weight` | 数字 | 否 | 已使用 | 排序权重，数字越小越靠前；管理端默认填写 `200` |
   | `icon` | 单行文本 | 否 | 已使用 | 手动指定的图标地址；留空时由网站自动获取 |
   | `desc` | 多行文本 | 否 | 预留 | 网站描述，当前页面暂未展示 |
   | `visible` | 复选框 | 否 | 预留 | 是否显示，建议默认勾选；当前页面暂未按此字段过滤 |

   > 最小可用字段是 `name`、`url`、`category` 和 `weight`。`icon`、`desc`、`visible` 可按需添加。`url` 当前应使用“单行文本”，不要设置为“链接”字段。

   ⚠️ 不要把字段改成“站点名称”“网址”“分类”“排序”等中文名称。添加链接接口写入的是上述英文字段，名称不一致会返回 `FieldNameNotFound`。

3. **添加示例数据**

   | name | url | category | weight | icon | desc | visible |
   |---|---|---|---:|---|---|---|
   | Google | https://google.com | 搜索 | 1 | 留空 | 搜索引擎 | 勾选 |
   | GitHub | https://github.com | 开发 | 2 | 留空 | 代码托管平台 | 勾选 |

4. **获取表格信息**
   - 复制多维表格的链接，从中提取 `app_token` 和 `table_id`
   - 链接格式：`https://xxx.feishu.cn/base/APP_TOKEN?table=TABLE_ID`
   ![参数说明](./images/4.png)

5. **开通并发布应用权限**
   - 进入飞书开放平台的应用后台，在“权限管理”中开通应用身份权限 `bitable:app`
   - 创建并发布一个应用版本；未发布的权限配置不会生效

6. **给多维表格添加文档应用**
   - 打开目标多维表格，点击右上角 `...` → “更多” → “添加文档应用”
   - 搜索并添加刚刚发布的应用
   - 确认应用对该多维表格具有“可管理”权限
   ![添加应用](./images/5.png)
   ![添加应用-6](./images/6.png)
   ![添加应用-7](./images/7.png)

## 常见错误

| 错误 | 常见原因 | 处理方式 |
|---|---|---|
| `FieldNameNotFound` | 表格字段名称与代码写入字段不一致 | 按本文把字段改为 `name`、`url`、`category`、`weight` 等英文字段 |
| `99991672` | 应用未开通多维表格 API 权限，或权限变更后未发布版本 | 开通 `bitable:app`，然后创建并发布新版本 |
| `91403 Forbidden` | 应用没有当前多维表格的访问权限 | 在目标表格中添加文档应用，并授予“可管理”权限 |
